# PPT 生成工具

`generate_presentation` 是个人 Agent 工作台的文件型工具。用户请求生成 PPT 时，规划器先注册并执行该工具；服务端使用 `pptxgenjs` 在本地生成 `.pptx`，再返回带时效签名的下载链接。生成动作因此不依赖模型是否原生支持文件输出。

当前版本使用稳定的五页结构：封面、背景与目标、核心方案、实施路径、风险与下一步。模型适合进一步补充每页内容与设计建议；文件生成、下载链接和 Trace 由后端工具负责。

面试口述：模型负责理解和内容建议，文件工具负责确定性地产出可下载文件。把两者分开后，可以替换 Ollama 或 OpenAI 兼容模型而不影响 PPTX 生成链路，也能在 Trace 中确认工具是否真正执行。
