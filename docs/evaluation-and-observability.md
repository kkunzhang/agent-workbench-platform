# 评测与可观测性

本项目区分两类证据。

- 固定评测集：`POST /api/lab/evals/run` 执行计算、时间、知识检索、真实 MCP 调用，适合提交前回归。
- 在线 Trace：每一次聊天保存 Planner、Tool、Model、Subagent、Answer Span，适合定位一次真实失败。

每轮运行至少检查非空回答、工具结果、45 秒延迟预算、步骤预算和工具 Trace。它们不是模型质量的全部指标；业务上线还应补充任务正确性、引用正确性、工具成功率、P95 延迟、Token 成本和人工偏好评测。

面试时应说明：离线评测回答“改动有没有回归”，在线 Trace 回答“这一次为什么失败”。两者缺一不可。
